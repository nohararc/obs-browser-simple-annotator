# OBS Browser Simple Annotator

OBS配信・録画中にリアルタイムで落書き（アノテーション）できる軽量ツールです。
単一HTMLファイルで動作し、外部ライブラリ不要。

![サンプル画像](./sample.png)

## 機能

- ペン / 消しゴム / 矢印 / テキストの4種類の描画ツール
- 5色のカラーパレット（赤・青・緑・黄・白）
- Undo（最大20回）/ 全消去
- キーボードショートカット対応
- 映像ソース選択（カメラ / 仮想カメラ / 画面キャプチャ）
- フローティングパレット（ドラッグ移動可、位置を記憶）

## セットアップ

### 必要なもの

- Google Chrome または Microsoft Edge
- OBS Studio

### 手順

**1. HTMLファイルをダウンロード**

`obs-browser-simple-annotator.html` をPC上の任意の場所に保存します。

**2. Chromeをアプリモードで起動**

Windows:
```cmd
"C:\Program Files\Google\Chrome\Application\chrome.exe" --app="file:///C:/path/to/obs-browser-simple-annotator.html"
```

Linux:
```bash
google-chrome --app="file:///path/to/obs-browser-simple-annotator.html"
```

> Edge の場合は `chrome.exe` を `msedge.exe` に置き換えてください。

**3. 映像ソースを選択**

起動時にダイアログが表示されます。

| ボタン | 用途 |
|--------|------|
| 📷 カメラ / 仮想カメラ | Webカメラ、OBS仮想カメラなどを背景に表示 |
| 🖥 画面・ウィンドウ | ゲーム画面やデスクトップを背景に表示 |
| 映像なしで開始 | 背景なしで描画のみ |

**4. OBSに取り込む**

OBS Studio で「ソース」→「+」→「**ウィンドウキャプチャ**」を追加し、Chromeのウィンドウを選択します。

## 使い方

### ツール

| ツール | 説明 |
|--------|------|
| ✏️ ペン | フリーハンドで線を描く |
| 🧹 消しゴム | 描いた線を消す |
| ➡️ 矢印 | ドラッグで矢印を描く |
| T テキスト | クリックした位置にテキストを入力（Enter で確定、Escape でキャンセル） |

### キーボードショートカット

| キー | 操作 |
|------|------|
| `P` | ペンツール |
| `E` | 消しゴムツール |
| `A` | 矢印ツール |
| `T` | テキストツール |
| `1`〜`5` | 色の切り替え（赤・青・緑・黄・白） |
| `Z` | 元に戻す（Undo） |
| `C` | 全消去 |

### 映像ソースの変更

パレット最下部の 📹 ボタンで映像ソースを再選択できます。
